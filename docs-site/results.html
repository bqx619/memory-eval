Result cards and comparisons

Each SUT × dataset evaluation produces a standard result card. Browse collected cards, inspect details, or compare 2–6 cards. Metric ⓘ controls explain definitions, formulas, direction, and aggregation. Data is extracted by memeval results build from reports/ into docs-site/results/index.js.

Adapter extension: evidence-stage diagnostics

When a run includes CogletNet work traces, this panel follows each question's evidence events (dataset gold.evidence_ids ) through ingestion, candidate retrieval, JEV admission, packing, and reading. Cells show question counts and their mean scores; select a cell to filter. This optional adapter diagnostic does not alter common scoring or coverage. Evidence labels are post-hoc and invisible to the SUT and decision service. Check stage attribution against original errors, returned content, and derivation rules.

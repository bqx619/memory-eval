BEAM 100K: collected runs

This page summarizes judge scores, ordering checks, category and episode results, failures, usage, and latency for collected BEAM 100K runs. Select a run for question-level answers, decisions, and coverage. Available adapter traces enable additional diagnostics. Report metrics come from report.json; direct-source counts, citation coverage, and evidence funnels are deterministically derived by scripts/build_beam_review.py from reports, datasets, and available traces. These diagnostics are distinct from official answer scoring. The page does not bundle real data; displayed content depends on the review resources provided.

Score distribution × run

Each question score averages rubric-item values 0 / 0.5 / 1. The 400-question distribution separates perfect, partial, zero, invalid, error, and unscheduled outcomes. Perfect-score rate divides scores of 1 by 400. Full-set mean imputes zero for unscored questions in this derived statistic and is shown beside the conditional scored-only mean. It reflects completion without changing original error or invalid statuses into scored answers.

Execution failures and invalid answers

Only runs with error, invalid, or unscheduled questions are listed. Errors are grouped by evaluator, bridge/transport, or native SUT origin. Invalid answers cannot be scored; unscheduled questions were not reached before interruption. Individual failures are available in each run view.

Usage and latency × run

Wall time includes ingestion, retrieval, answering, and judging; resumed runs sum attempts. Native SUT usage is reported by the adapter; gateway usage is metered by the evaluator relay; none means no remote model calls declared or local models only. Missing accounting is not zero usage. Evaluator prompt tokens cover reader and judge calls. Retrieval and answer latency use per-question medians.

Adapter extension: evidence funnel

This panel uses CogletNet work traces to follow question evidence events (dataset gold.evidence_ids ) through ingestion, candidate retrieval, JEV admission, packing, and reading. Cells show question counts and mean scores. Select a cell for filtered run details, category funnels, and per-question evidence tables. This adapter-specific diagnostic is not a common SUT metric or ranking criterion. Evidence labels are post-hoc and invisible to the SUT and decision service. Read the funnel alongside missing-source and derivation limitations.

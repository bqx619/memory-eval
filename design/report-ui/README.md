# Report UI resources

`report.css`, `report.js`, and `shell.html` are the maintained report template. Their copies in `internal/report/assets/` must match byte for byte; Go embeds those copies. The source templates are functional inputs, not disposable design artifacts. `build_prototype.py` produces optional previews; current reports are generated by `internal/report/render.go`.

## Synchronization and data

1. Edit the design source, then copy it unchanged to the embedded directory. `TestEmbeddedAssetsMatchDesign` verifies synchronization.
2. Single-run and comparison pages share the shell. It receives `{"reports":[...],"compare":null}` (or a comparison object) in the `#memeval-data` JSON element.
3. JSON injection escapes `</` as `<\/` and `<!--` as `\u003c!--`, preserving decoded values. Each `/*CSS*/`, `/*JS*/`, and `/*DATA*/` marker occurs once and is replaced once. `TestJSONInjectionRoundTrip` checks adversarial text and literal marker strings.
4. No external fonts, scripts, or resources are needed. Missing values display as `—`, never fabricated zeros or success states.
5. Report v2 fields include summary/status counts, timings, returned characters, official and memory-only scores, categories, protocol and fidelity, isolation, model configuration, billing, cases, seed, run/suite hashes, environment, and framework version. Comparisons include paired cases, clusters, delta, confidence interval, exclusions, and protocol differences.

The disclosure panels also consume `isolation.container`, `data_flow`, `sut.llm`, and `billing.sut`. Runtime `none` does not imply evaluator model calls or image builds had zero egress. Reader input and protocol deviations remain comparison conditions even when not repeated on every panel. Rendering converts the report's repeats object into a numeric badge plus repeat statistics for compatibility.

## Presentation rules

English is the interface language. Keep metric IDs, report values, source text, and provenance unchanged. Use both text and icons for statuses; colors alone do not communicate enforcement. Category charts provide a table view. Unknown cost stays unknown. A missing judge score is explained explicitly. Mobile layouts wrap cards and scroll wide tables rather than stretching the page.

Category labels size to their content, with truncation and a full-text tooltip. Deterministic benchmarks show their primary metric rather than a nonexistent judge pass rate. Official details, per-type metrics, and protocol deviations remain separate from retrieval diagnostics.

## Offline checks

```sh
node --check design/report-ui/report.js
GOPROXY=off GOSUMDB=off GOFLAGS=-mod=readonly go test ./internal/report -run 'TestEmbeddedAssetsMatchDesign|TestJSONInjectionRoundTrip|TestRepeatStatisticsKeepNumericUIBadge' -count=1
```

These checks require neither Docker nor real SUTs. A syntax test is not visual acceptance; inspect desktop and mobile layouts after layout changes. Preserve Unicode input in report data even though interface copy is English.

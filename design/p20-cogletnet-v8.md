## Purpose and outcome

Two variants compared unrestricted hierarchy depth with a two-level cap using the same upstream snapshot and approximately ten-percent summary recipe. Top-level nodes without parents required a transparent token-count fallback from accepted input summaries.

## Interpretation and limits

Compare scores on the common scored subset and disclose source, model, level cap, token-count provenance, and cost. A more compressed hierarchy is not necessarily a better memory system. The unrestricted variant grew only to L2, with 48 L2 nodes; this experiment did not establish the value of substantially deeper hierarchies.

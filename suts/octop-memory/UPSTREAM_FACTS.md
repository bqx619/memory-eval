## octop-memory 1.0.1 distribution verification (2026-10-16)

The verified object was the locked distribution, not the upstream main branch: Python 3.12.13, SQLite 3.50.4 with FTS5, package 1.0.1. Dependency declarations and hashes are in requirements.in/requirements.lock.txt. `scripts/verify_octop_upstream.py` records the reproducible probe; observations are in `reports/m1b-verification/upstream-facts.json`. These describe historical host execution. P8 K1b retired host isolation; `internal/adapter/octop/integration_test.go` temporarily retained protocol checks using the none backend, with real execution migration to containers pending in that record.

1. **Entry and probe.** `adapters/bridge/server.py:main/_run_probe` supports namespace, db-path, backend sqlite, config-json, probe and log-level. The actual probe returned ok=true, protocol_version=1.0, octop_memory_version=1.0.1, python_version=3.12.13, sqlite_version=3.50.4, fts5=true, python_executable and fts5_error=null. Probe short-circuits before argparse and is absent from help. Log levels accept lowercase debug/info/warning/error; the manifest uses warning.
2. **Frames and handshake.** `server.py:serve` parses one request per line, synchronously writes and flushes JSON-RPC 2.0 responses, and logs to stderr. Multiple real-process calls echoed their IDs correctly. `_handshake` returns protocol 1.0, server octop-memory.bridge, the original namespace and client_version. Go Reset validates the first three; it does not call a nonexistent reset RPC.
3. **Capture and counts.** MemoryRuntime.capture accepts session_id/thread_id/user/host/events and reads each id/event_type/content/payload/timestamp_iso. Actual ingestion preserved IDs and 2023 timestamps; `ok` was accepted with min_message_chars=0. It returns integer accepted/skipped_recall_marker/skipped_too_short/skipped_role/skipped_tool_result counts. RawEventType lists user_message, assistant_message, tool_call, tool_result, host_memory_write, session_start, session_end, compaction and manual, but capture does not strictly validate arbitrary strings against that Literal. Go sends only user_message/assistant_message.
4. **Configuration and retrieval.** Defaults are min_message_chars=12, include_roles=[user,assistant], skip_memory_echo=true and privacy.redact_secrets=true. The manifest sets min_message_chars=0, redact_secrets=false and raw_policy=always, confirmed by stats and simultaneous atom/raw hits. memory_search passes raw_policy to recall_for_prompt and applies `_apply_raw_policy` again; supported values are fallback/always/never. MemoryService.recall uses default fallback, while MemoryService.search uses configuration. This service facade differs from core.Memory.recall, which queries tree nodes.
5. **Search layers and page ambiguity.** memory_search(query,maxResults,corpus=memory) returned hits/total/empty_reason; hits contain path, score=null, snippet, layer, role_hint, occurred_at and source_id. Corpus supports memory/wiki/all/sessions. recall_for_prompt projects internal atom/page_headline to atom and raw/episode to raw; optional host indexing adds host_file. Thus bridge output has atom/raw/host_file, not independent vector/episode/page hits. stats.layer_order=[atom,host_file,page,raw] is sorting configuration, not evidence of page output. An actual page-contract hit had layer=atom, source_id=page-contract and path=atom/page-contract.md; get_atom and memory_get both returned -32010. Internal episode IDs likewise are not public raw-event IDs; M1b creates no episodes. The test created pages via the public Python API (no page-creation RPC exists), then searched/read through the bridge.
6. **Provenance and full text.** get_atom returns AtomCard raw_event_ids/quote_event_id; real promote_candidate tests covered single, multiple and duplicate sources. Raw paths use raw/YYYY-MM-DD/id.md. Actual memory_get returned complete Markdown with id/event_type/role/timestamp/session_id front matter, metadata{id,event_type,session_id} and truncated=false. Atom metadata contains only id/entity_id/importance/confidence; page metadata only entity_id/version/dirty; neither supplies raw sources. create_atom creates a new manual raw event instead of binding a supplied raw ID. Positive tests therefore create a candidate and promote it through the bridge; create_atom separately verifies rejection of unknown provenance.
7. **Content transformations.** capture/_strip_think_tags/_prepare_content remove paired think tags, leading orphan closing tags and trailing unclosed tags. Complete recall markers are skipped with default skip_memory_echo=true. Invalid/missing timestamp_iso parses to None and falls back to datetime.now(UTC), confirmed by an actual invalid-time write. redact_secrets=true replaces the test sk- string with [REDACTED]; false disables built-in redaction, but custom redact_patterns remain independent. Additional transformations such as store_raw_content=false and tool-payload cleanup exist but are not enabled in M1b.
8. **Global paths and environment.** The upstream default database is `$OCTOPMEMORY_HOME/<ns>/memory.sqlite`, otherwise `~/.octopmemory/<ns>/memory.sqlite`. CLI configuration uses `~/.octop-memory/config.json` and OCTOP_MEMORY_BACKEND/DB/DSN, but the bridge does not call that loading chain. Bridge OCTOP_MEMORY_DSN applies only to PostgreSQL; core OCTOP_MEMORY_CHECKPOINT_DEDUP affects checkpoints only. The default LLM credential variable is OCTOPMEMORY_LLM_API_KEY. The tested manifest declared no env/env_passthrough; the process received the M1a allowlist, episode HOME/XDG and an explicit episode database, without host-files-root. Historical mtime checks found no writes to upstream global directories. Mtime establishes only write observations; the no-read conclusion also depended on source inspection and the then-current isolation/environment configuration.
9. **Extraction and LLM keys (inspection only).** `_extract_impl` reads session_id, incremental (default true), promote/regen_pages (default true), max_candidates and max_tokens. Responses include session_id/events_considered/events_extracted/candidates/warnings/cap_warning/failure_reason/llm_calls/promotion/pages; episodes is added later and may be absent on empty input or extraction failure. Promotion includes promoted/merged/conflicts/needs_review/dropped/llm_calls; pages includes regenerated/failed/llm_calls. `_build_llm_client({})` returned NoopLLMClient; the unconfigured error becomes `failure_reason:"LLM call failed: ..."`, without marking events extracted. This matches the earlier design observation llm_calls=1 and promotion/pages=null; extract was not executed in this verification. OpenAICompatClient.from_config accepts endpoint (alias base_url), model, model_heavy, api_key, api_key_env, timeout_seconds and max_retries; endpoint/model are required. api_key_env defaults to OCTOPMEMORY_LLM_API_KEY. Synthetic credential parsing used no HTTP calls. retry_backoff_seconds exists in the constructor but is not forwarded by from_config; invalid/incomplete configuration falls back to Noop.
10. **Readiness barrier.** stats returns namespace/counts/config/host_files. Actual counts included raw_events/atoms/entities/dirty_pages. Three captured events gave raw_events=3; promotion/page creation did not increase it. Go Ready requires raw_events to equal cumulative accepted; missing/mismatching counts are ingest_failed. A foreign raw write in the contract test confirmed barrier rejection.

### Adapter assumptions and limits

- Missing public timestamps use 2000-01-01 UTC plus sequence seconds, preserving suite events and explicit times. This avoids now()-dependent full-text/order drift, without recovering a real timestamp. protocol.changes and changes_from_v1 disclose it. Upstream recency still uses current time; cross-period determinism is not claimed.
- Capture supports one session_id. NeedsSessionBatching splits original batches at consecutive session boundaries; direct mixed-session ingestion raises ContractError. Missing sessions use s0.
- Empty shouldOnlyInclude means no positive labels and falls back to nonempty mustInclude; both empty are skipped. The historical pmb.ImportAs projection preserved M0 inputs, produced 43 retrieval cases and disclosed 34 skipped cases.
- Native integration does not call extract, patch upstream, apply substitute user/scope filtering or truncate full text. Budget violations remain contract results. Only lookup errors -32010/-32011 permit fallback; timeouts, process exits and protocol errors remain execution errors.
- get_atom raw_event_ids are deduplicated and all must belong to the accepted prefix. Where page/other-layer metadata is available, raw_event_ids take precedence, then quote_event_id; neither present yields unsupported_item and an unsupported case. Atom/page IDs are not event IDs, and hits are not silently discarded. Summary untraceable_hits includes failed cases.
- Single-cluster comparisons require ci95=null; this does not imply identical point estimates. Linux execution was not verified in the original distribution check.
